# HR Analytics Dashboard 📊

An interactive HR Analytics Dashboard developed using Microsoft Power BI to analyze employee attrition, workforce distribution, salary trends, job satisfaction, overtime analysis, and overall employee insights.

---

## 🚀 Project Overview

This project focuses on transforming raw HR employee data into meaningful business insights using data visualization and analytics techniques. The dashboard helps HR teams understand employee behavior, identify attrition trends, and support data-driven decision-making.

---

## 🛠️ Tools & Technologies Used

* Microsoft Power BI
* Power Query
* DAX (Data Analysis Expressions)
* Microsoft Excel

---

## 📌 Key Dashboard Features

* Total Employees KPI
* Attrition Rate Analysis
* Department-wise Employee Distribution
* Average Salary by Job Role
* Overtime vs Attrition Analysis
* Gender Distribution
* Job Satisfaction Insights
* Interactive Slicers & Filters

---

## 📈 Business Insights

* Identified departments with higher employee attrition
* Analyzed salary trends across job roles
* Compared overtime impact on employee attrition
* Evaluated workforce distribution and employee demographics

---

## 🎯 Project Objective

The main objective of this project is to help organizations monitor workforce trends, improve employee retention, and make strategic HR decisions through interactive dashboards and visual analytics.
